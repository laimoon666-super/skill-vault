# 插件清单

本仓库对插件分两类处理：

| 类别 | 是否备份文件 | 原因 |
|:---|:---|:---|
| **自研插件** | ✅ **完整备份源码** | 商店里没有，丢了就真没了；且多以本地链接方式挂载，包管理器拉不回来 |
| **第三方插件** | ❌ 只记录名称与来源 | 官方商店随时可重装，且体积大、更新快 |

---

## 一、自研插件（完整备份）

源码存放在本仓库 `plugins/<插件名>/`。按各插件自己的 `README.md` 手动恢复。

| 插件名 | 平台 | 目录 | 版本 | 用途 | 恢复方式 |
|:---|:---|:---|:---|:---|:---|
| `token-stats` | 🖥️ **仅 DSH** | [`plugins/token-stats/`](./token-stats/) | 1.0.0 | DSH 桌面端 Token 用量统计面板：折叠全部会话日志，按 provider / 模型统计 token 消耗，支持今日 / 近 7 天 / 近 30 天 / 自定义区间 | 见 [`token-stats/README.md`](./token-stats/README.md)：改 profile 的 `package.json`（`bundles` 加一行 + `link:` 依赖）后 `pnpm install` |

---

## 二、第三方插件（只记录不备份）

### 为什么不备份文件

这些插件从官方商店 / 远程市场下载，随时可以重装。备份它们没有意义：

- 单个插件可能只有几 MB，但缓存目录累计可达数百 MB（含二进制运行时）
- 官方会持续更新版本，备份下来的是旧快照
- 重装只要一条命令

**需要还原时**：照下表把插件重新装一遍即可，不用从本仓库复制文件。

### 安装方式速查

| 平台 | 命令 |
|---|---|
| Codex | `codex plugin install <name>` |
| Claude Code | `/plugin install <name>@<marketplace>` |
| DSH | 在 Agent 预设界面导入 |
