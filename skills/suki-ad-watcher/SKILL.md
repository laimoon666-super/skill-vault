# 📱 Suki 看广告得贝壳 AI 视觉自动化 Skill 指南

本 Skill 专用于在 Android 真机（特别是荣耀 MagicOS 系统）上自动化执行 **Suki App** 的每日与限时广告观看任务，确保贝壳奖励稳定到账且具备完整的证据链闭环。

---

## 1. 设备环境与连接规范

### 1.1 目标设备档案
- **机型**: 荣耀 HONOR X60 Pro (`BRP-AN80`)
- **系统**: MagicOS 9.0.0 (Android 15)
- **屏幕分辨率**: 1224 × 2700 (DPI: 480)
- **默认 ADB 目标**: `192.168.2.5:5555` (Wi-Fi 模式)
- **USB 硬件 VID**: `0x339B` (荣耀特有 USB 描述符)

### 1.2 连接自愈机制
每次调用前必须确保 ADB 连接在线：
```bash
# 检查设备连接
adb connect 192.168.2.5:5555
adb -s 192.168.2.5:5555 devices
```
如果 USB 连接出现 WinUSB 未识别，使用自带的 `usb_adb.py` 发送 RSA 握手激活 `tcpip:5555`。

## 2. 自动化执行核心原则（SOP）

### 2.1 单步视觉验证原则（Single-Step Visual Verification）
- **严禁盲点或多步并发点击**：每执行一次关键点击（如“去完成”、“跳过”、“✕”、“领取奖励”），必须 `sleep 1~2s` 并截屏一次，由 AI/视觉模型读取页面当前状态后再决定下一步。
- 截图保存于 `手机自动化管理/screenshots/` 目录下。

### 2.2 遮罩优先清除与重试原则（防卡死关键）
- **现象**：点击“去完成”或“去领取”无反应。
- **原因**：广告 SDK 或 Flutter 界面存在全屏透明穿透拦截遮罩。
- **清除 SOP**：
  1. 先点击中立安全盲区 `(300, 1400)` 穿透/触发遮罩。
  2. 等待 `0.5s`。
  3. 再次点击目标功能按钮。
  4. 严禁直接无脑按物理返回键（`KEYEVENT_BACK`）。

### 2.3 广告起播与倒计时等待
- 起播确认：点击“去完成”后 2s 截屏，确认黑屏加载或视频 SurfaceView 正在播放。
- 播放等待：常规激励视频广告倒计时为 30~35s。
- 遇到可跳过提示（如 `跳过` 或 `激励已下发`），优先点击跳过。

## 4. 终局双重证据链闭环

任务完成前必须满足以下**双重证据**：
1. **状态闭环**：任务中心列表中，所有广告任务（「看3次激励视频」、「限时看激励视频」等）的按钮均已变为 **【明日再来】**，进度为 `(3/3)`。
2. **数值闭环**：任务前后的贝壳总数具有正向增量（例如 3次常规 +210，3次限时 +300，累计 +510~520 贝壳）。
